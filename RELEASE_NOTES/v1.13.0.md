Der Viewer-Modus kann jetzt auch die **Standortkarte** zeigen — für den
Bildschirm im Leitstand oder beim Wachschutz: eine Stadtkarte, auf der jeder
Standort grün, gelb oder rot ist.

> **Für bestehende Kiosk-Ausgaben ändert sich nichts.** Ohne den neuen
> `map`-Abschnitt bleibt es beim reinen Status-Tab — ein Update darf keinem
> laufenden Bildschirm ungefragt einen neuen Tab dazustellen.

## Der `map`-Abschnitt in `viewer.json`

```jsonc
"map": {
  "show": true,                    // ohne das bleibt der Bereiche-Tab weg
  "area": "Stadthaus",             // Startbereich per Name; leer = ganze Stadt
  "zoom": 16,                      // 0 = automatisch einpassen
  "layer": "Topographisch grau",   // Name aus den Kartenquellen
  "tree": false                    // Baum links weg -> reine Kartenwand
}
```

`area` ist der **Name** des Bereichs, nicht seine Nummer — die steht nirgends,
wo du sie ablesen könntest. Gibt es den Namen nicht, bleibt die Karte auf der
Gesamtübersicht und schreibt eine Zeile ins Log, statt die Vorgabe stumm zu
verschlucken.

Für eine reine Kartenwand schaltet `"tree": false` die Liste links ab; die Karte
bekommt dann die volle Breite.

## Rein lesend

Anlegen, Umbenennen, Löschen, Hosts zuweisen, Zeichnen und Importieren sind im
Viewer-Modus ohnehin nicht vorhanden. Der neue Abschnitt schaltet nichts davon
frei — auch das Kontextmenü der Karte bleibt zu.

Die Werte sind **Startwerte**, keine Sperre: Wer vor dem Bildschirm steht, darf
schieben und zoomen. Nach einem Neustart steht wieder die vorgesehene Sicht da.

## Die Ampel gehört zur Sicht

Welche Hosts die Farbe eines Standorts bestimmen, entscheidet weiterhin allein
der Filter aus `view`. Derselbe Serverraum ist für das DB-Team grün und für den
Wachschutz rot, wenn die USV Netzausfall meldet — die Karte ist geteilt, die
Linse nicht.

Damit die Karte auch ohne Internet sofort da ist, lohnt vor dem Ausrollen einmal
**„Karten vorladen"** im normalen Cockpit; der gemeinsame Kachelspeicher
(`MapTileSharePath`) steht danach allen zur Verfügung.
