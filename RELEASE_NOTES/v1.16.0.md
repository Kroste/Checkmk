## Für Entwickler

Die Submodul-Adressen in `.gitmodules` zeigen jetzt auf `LHP542`. In einer
bestehenden Arbeitskopie einmal nachziehen:

```bash
git submodule sync --recursive
```

Ohne das bleibt die alte Adresse im lokalen `.git/config` stehen. Ein Fehler
entsteht dadurch nicht — GitHub leitet weiter —, aber sauber ist es so.

Das eigene `origin` genauso:

```bash
git remote set-url origin https://github.com/LHP542/Checkmk.git
```
